## Integration Check

Initial integration checker verdict: `gaps_found`.

Findings fixed before final audit:

- SOAK-02: real-session scorecard JSON could bypass safety checks because
  `would_speak` is `None`. Fixed by adding `unsafe_automatic_playback` audit
  evidence and safety-soak violation handling.
- FIX-03: rehearsal scorecard remediation rerun used only `artifact.json`.
  Fixed by preserving a non-exported `source_path` and rendering the runnable
  rehearsal path in remediation output.
- SOAK-04: safety-soak only printed generic next actions. Fixed by adding
  `hints_from_safety_soak()` and rendering remediation hints in CLI output.
- REH-03: rehearsal JSON retained transcript snippets and volatile
  `live_control_state.last_trigger`. Fixed by sanitizing rehearsal JSON export.
