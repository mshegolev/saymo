## Summary

Milestone v1.9 achieved its definition of done at the code, artifact, CLI,
test, documentation, and integration levels. The milestone now provides one
call-ready launch gate, provider/audio readiness checks, local call-control
daemon and LaunchAgent support, fail-closed realtime automatic answering, and
sanitized launch/realtime evidence that feeds scorecards, safety-soak, and
remediation.

The initial integration audit found two blocking cross-phase gaps. Both were
closed in `.planning/phases/41-v19-integration-gap-closure/41-01-SUMMARY.md`:

- Prepared-audio metadata freshness now uses the saved Obsidian daily-note hash
  that call-ready later checks.
- Runtime realtime JSONL now emits sanitized lifecycle/playback labels such as
  `launch-start`, `launch-end`, `playback-attempted`, `stop-requested`,
  `cancel-playback`, and `playback-timeout`.

## Residual Human Smoke

These checks remain human-only and should be run before trusting a real
meeting:

1. `uv run saymo call-ready -p standup --provider glip --output ~/.saymo/live_control/standup/call-ready.json`
2. Run a controlled live/rehearsal realtime session that writes `~/.saymo/live_control/standup/realtime-decisions.jsonl`.
3. `uv run saymo session-scorecard -p standup --launch-json ~/.saymo/live_control/standup/call-ready.json --realtime-jsonl ~/.saymo/live_control/standup/realtime-decisions.jsonl --rehearsal <rehearsal.json> --json-output <scorecard.json>`
4. `uv run saymo safety-soak -p standup --scorecard-json <scorecard.json>`

Expected result: safe real evidence passes; unsafe real evidence fails with
sanitized remediation and rerun commands.
