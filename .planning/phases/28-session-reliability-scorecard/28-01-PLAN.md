# Plan 28-01: Add scorecard data model and source loaders

**Status:** done

## Goal

Create a sanitized session scorecard contract that can be built from a saved
Phase 27 rehearsal artifact and can later accept real-session regression and
live-control evidence.

## Tasks

- Add `saymo.analysis.session_scorecard` with dataclasses for scorecard
  sections, trigger metrics, playback/safety metrics, warnings, and source
  metadata.
- Add JSON serialization/deserialization helpers that omit raw transcript,
  raw audio, secrets, and absolute local content by default.
- Add a loader that builds a scorecard from one rehearsal artifact JSON path.
- Add tests that first fail for the desired scorecard JSON contract and
  rehearsal loader behavior.
