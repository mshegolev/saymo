# Phase 43 Plan 02: F5 A/B Timing Preview and Review Artifacts

<objective>
Implement privacy-safe A/B timing preview and review artifacts so the operator
can compare current timing with candidate presets before applying changes.
</objective>

## Tasks

<task id="43-02-01" name="Write RED tests for sanitized A/B artifact helpers">
<read_first>
- tests/analysis/test_voice_benchmark.py
- saymo/analysis/voice_benchmark.py
- .planning/phases/43-f5-pause-presets-and-a-b-timing-review/43-CONTEXT.md
</read_first>
<action>
Create `tests/analysis/test_f5_timing_review.py` with tests that expect:
1. `write_f5_timing_preview_artifacts(run_dir, records, preview_text="PRIVATE")`
   writes `manifest.json`, `review.json`, and `timing-report.md`.
2. Manifest records include preset IDs, timing values, text SHA-256, and output
   WAV path, but not `PRIVATE`.
3. `record_f5_timing_preference(run_dir, preferred="candidate", notes="ok")`
   writes review JSON with `recommended_preset` equal to candidate preset ID and
   `timing-report.md` contains `recommendation: <preset>`.
</action>
<acceptance_criteria>
- `uv run pytest tests/analysis/test_f5_timing_review.py -q` fails before production code with missing module/functions.
</acceptance_criteria>
</task>

<task id="43-02-02" name="Implement sanitized timing review helper">
<read_first>
- saymo/analysis/voice_benchmark.py
- saymo/tts/f5_presets.py
- tests/analysis/test_f5_timing_review.py
</read_first>
<action>
Create `saymo/analysis/f5_timing_review.py` with:
- dataclass `F5TimingPreviewRecord`
- `build_f5_timing_record(label, preset, output_wav, preview_text)`
- `write_f5_timing_preview_artifacts(run_dir, records, preview_text="")`
- `record_f5_timing_preference(run_dir, preferred, notes="")`
- `render_f5_timing_report(manifest, review)`

Artifacts must store only `label`, `preset`, `timing`, `output_wav`,
`text_sha256`, `created_at`, `preferred`, `notes`, and `recommended_preset`.
They must not store raw preview text, prompt text, meeting transcript text,
secrets, or audio bytes.
</action>
<acceptance_criteria>
- `saymo/analysis/f5_timing_review.py` contains `class F5TimingPreviewRecord`.
- `uv run pytest tests/analysis/test_f5_timing_review.py -q` passes.
- `rg "PRIVATE" <tmp run dir artifacts>` in tests finds no private preview text.
</acceptance_criteria>
</task>

<task id="43-02-04" name="Implement preview/review CLI and docs">
<read_first>
- saymo/commands/voice_clone.py
- docs/voice-clone-shootout.md
- tests/test_voice_clone_cli.py
</read_first>
<action>
Add `f5-presets preview <preset>` with options:
- `--text`, required preview text
- `--output-dir`, optional run directory
- `--dry-run`, writes artifacts without synthesis

For dry-run, create placeholder record paths `current.wav` and
`<preset>.wav` without writing audio bytes. For non-dry-run, synthesize current
timing and candidate timing through the existing preview path, then write WAV
files and artifacts.

Add `f5-presets review <run-dir>` with options:
- `--preferred`, choice `current|candidate`
- `--notes`, default empty

Update docs to show:
- `saymo f5-presets list`
- `saymo f5-presets preview deliberate --text "..."`
- `saymo f5-presets review <run-dir> --preferred candidate`
- `saymo f5-presets apply deliberate --profile standup`
</action>
