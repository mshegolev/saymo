# Plan 27-02: Add profile-scoped rehearsal command and dry-run path

**Status:** done

## Goal

Expose a user-facing command that runs a local rehearsal for one profile
without joining a real meeting or sending audio into call output.

## Tasks

- Add `saymo rehearsal` CLI command.
- Support `--profile/-p`, `--text`, `--dry-run/--no-dry-run`, `--provider`,
  `--output-dir`, `--json-output`, and `--no-hotkey-probe`.
- In dry-run mode, print would-speak/would-block decisions and never invoke
  playback.
- Write the rehearsal artifact and print its path.

## Completed

- Added `saymo rehearsal`.
- Added profile, text, dry-run, provider, output-dir, json-output, and hotkey
  probe flags.
- Dry-run output reports `auto action`, `would speak`, and blocked reason.
- Command writes an artifact path and optional exact JSON output.
