# Plan 44-01: Stale-Cache Cost Warnings and Targeted Repair Commands

## Scope

Add read-only cache diagnostics that tell the user whether prepared audio and
response-cache files are current, missing, stale, or partial, and what targeted
command to run.

## Files

- Add: `saymo/analysis/cache_advice.py`
- Modify: `saymo/commands/tests.py`
- Modify: `saymo/analysis/launch_cache.py`
- Modify: `saymo/analysis/remediation.py`
- Add/modify tests:
  - `tests/analysis/test_cache_advice.py`
  - `tests/analysis/test_launch_readiness.py`
  - `tests/analysis/test_remediation.py`

## TDD Tasks

1. RED: Add cache-advice tests for:
   - prepared audio ready -> no regeneration action
   - prepared audio stale -> explicit expensive F5 warning and `saymo prepare -p standup`
   - response cache partial/stale -> explicit expensive warning and `saymo prepare-responses`
   - response cache ready -> no regeneration action
2. RED: Add CLI test for `saymo cache-status -p standup` proving the output is
   sanitized, shows cost warning, and prints targeted commands.
3. Implement `CacheAdvice` dataclass and helpers:
   - `prepared_audio_cache_advice(config, audio_path, profile, team=False)`
   - `response_cache_advice(config, profile)`
4. Implement `saymo cache-status` as a read-only command in the diagnostics CLI
   module.
5. Update launch/readiness and remediation actions so stale response/prepared
   cache failures point at targeted commands instead of generic regeneration.
6. GREEN: run focused cache/remediation/CLI tests.

## Verification

```bash
uv run pytest tests/analysis/test_cache_advice.py tests/analysis/test_launch_readiness.py tests/analysis/test_remediation.py tests/test_cache_status_cli.py -q
```

## Safety

- No cache files are deleted or regenerated by diagnostics.
- Output must not include response variants, prompts, daily-note text, raw audio,
  or secrets.
