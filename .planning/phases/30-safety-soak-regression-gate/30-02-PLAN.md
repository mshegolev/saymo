# Plan 30-02: Add safety invariants for handbrake and approval gates

**Status:** complete

## Goal

Fail the soak when automatic speaking violates handbrake or approval boundaries.

## Tasks

- Detect would-speak while auto-answer is off.
- Detect would-speak while manual takeover or hard-disable is active.
- Surface violations with artifact labels and remediation-friendly details.
- Add tests for pass and fail cases.

## Verification

- `uv run pytest tests/analysis/test_safety_soak.py`

## Result

- Safety soak fails when `would_speak` is true while auto-answer is off,
  manual takeover is active, hard-disable is active, or the playback gate
  reports an unapproved draft.
- Blocked automatic playback is counted as safety evidence, not treated as a
  failure by itself.
