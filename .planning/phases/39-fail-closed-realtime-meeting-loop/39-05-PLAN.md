<interfaces>
New event contract:
```python
@dataclass(frozen=True)
class RealtimeDecisionEvent:
    created_at: str
    profile: str
    provider: str
    outcome: Literal["spoke", "skipped", "blocked"]
    label: str
    source: str = ""
    automatic: bool = True
    intent_key: str = ""
    confidence: float | None = None
    audio_path: str = ""
    detail: str = ""

    def to_dict(self) -> dict[str, Any]: ...

def realtime_event_log_path(profile: str, *, base_dir=None) -> Path: ...
def append_realtime_decision_event(profile: str, event: RealtimeDecisionEvent, *, base_dir=None) -> Path: ...
```

Allowed labels include:
`launch-readiness-blocked`, `response-cache-hit`, `cache-miss-blocked`, `fallback-blocked`, `provider-blocked`, `handbrake-blocked`, `manual-standup-requested`, `manual-standup-blocked`, `addressing-skip`, and `deterministic-skip`.
</interfaces>
