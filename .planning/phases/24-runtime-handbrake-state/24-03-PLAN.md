# Plan 24-03: Normalize stop and manual takeover recovery behavior

**Status:** done

## Completed

- Routed stop through the same live-control action handler for hotkeys, panel,
  and scriptable CLI commands.
- Manual takeover stops playback, pauses auto-answer flow, and uses existing
  best-effort provider mic switching.
- Toggle behavior now refuses ambiguous auto-answer changes while takeover is
  active.
- Hard-disable stops playback and keeps automatic answering disabled until the
  operator explicitly re-enables it.
