# Phase 41 Plan 01: Silent Breath F5 Pacing

## Objective

Replace audible breath splices in F5 natural pacing with configurable silent
breath pauses.

## Tasks

### Task 1: RED - Silent Breath Contract

- Add a failing test in `tests/tts/test_f5tts.py` proving paragraph breath
  points are pure silence.
- Expected RED: existing implementation contains non-zero samples from the
  reference breath splice.

### Task 2: GREEN - Remove Audible Breath Splicing

- Remove F5 stitching dependency on `load_breath_sample()`.
- Add `silent_breath_pause_seconds` to `F5TTSConfig`.
- Materialize paragraph and continuation breath points as zero-valued silence.
- Update `config.example.yaml`, docs, and config tests.

### Task 3: Local Config and Preview

- Back up `~/.saymo/config.yaml`.
- Replace `breath_gain` with `silent_breath_pause_seconds`.
- Generate a short local preview WAV.
- Record the `afplay` command for user review.
