    - Test: text `One. Two. Three.\n\nFour - five.` or equivalent punctuation produces one sentence pause, one silent_breath continuation pause, one paragraph pause, and one clause pause under the approved timing defaults.

    - Test: the returned dict is JSON-serializable and contains no raw source text or prepared text.

  <action>
    Create `saymo/analysis/f5_timing_metrics.py` with a small deterministic metrics builder. Reuse `f5_timing_snapshot()`, `prepare_for_natural_pacing()`, and `split_for_tts()`; do not reimplement punctuation splitting.

    Implement `build_f5_timing_metrics(config, *, text, preset_id=None, audio_duration_seconds=None) -> dict[str, Any]` with this artifact shape:
    - `estimated_total_duration_seconds`: estimated spoken duration plus all pause seconds, rounded to 2 decimals.
    - `audio_duration_seconds`: rounded to 2 decimals when supplied, otherwise `None`.
    - `spoken_chars`: character count from joined spoken chunks after natural pacing markers are removed.
    - `spoken_words`: word count from joined spoken chunks.
    - `chars_per_second`: `spoken_chars / display_duration`, rounded to 2 decimals, where `display_duration` is `audio_duration_seconds` when supplied, else `estimated_total_duration_seconds`.
    - `words_per_minute`: `spoken_words / display_duration * 60`, rounded to 2 decimals.
    - `pause_distribution`: exactly four groups: `sentence`, `clause`, `paragraph`, `silent_breath`; each group contains `count` and rounded `seconds`.

    Use a deterministic dry-run speech estimate such as `spoken_chars / (14.0 * f5_speed)` where `f5_speed` is `config.tts.f5tts.speed` or `1.0`. Clamp durations so empty text does not divide by zero. Count pauses by walking `split_for_tts(prepare_for_natural_pacing(...))` the same way `F5TTSCloneTTS._synthesize_natural_sync()` does:
    - float chunks count as `clause` using their own seconds.
    - empty string chunks count as `paragraph` using `paragraph_pause_seconds`.
    - adjacent spoken chunks count as `sentence` unless `breath_interval_sentences` triggers a `silent_breath` pause.
    - continuation silent-breath pauses are separate from paragraph pauses even though the duration value may match.

    Do not import or call `load_breath_sample()`. Do not add future Phase 47 behavior, recommendation scoring, or any persistence of raw manual/corpus text.
  </action>
