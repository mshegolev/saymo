```python
class CallControlAgentStatus:
    profile: str

    plist_path: str

    stderr_log_path: str
    installed: bool
    plist_current: bool
    loaded: bool
    heartbeat_fresh: bool

    hotkeys_active: bool

    classification: str
    detail: str

def collect_call_control_agent_status(spec: LaunchAgentSpec, *, base_dir=None, now=None, max_heartbeat_age_seconds: float = 5.0, runner=None) -> CallControlAgentStatus: ...
```

Required classifications:
`not_installed`, `installed_not_loaded`, `running`, `stale_heartbeat`, `crash_loop`, `hotkey_permission_blocked`, `plist_drift`, `status_unavailable`.
</interfaces>

<guardrails>
- `collect_call_control_agent_status()` and `call-control-agent status` are read-only.
- Do not call bootstrap, bootout, kickstart, install, uninstall, append_control_command, provider APIs, audio APIs, config writers, or Chrome kill commands from status.
- Do not parse `launchctl print` as a stable API; use return code for loaded truth and small best-effort crash/throttle hints only.
- Daemon-reported hotkey status in heartbeat is the LaunchAgent permission proof; terminal hotkey-doctor is supporting context only.
</guardrails>
