# Phase 43 Plan 01: F5 Pause Preset Catalog and Apply Flow

<objective>
Implement the preset catalog and explicit apply path that lets the operator
select F5 timing without hand-editing YAML, while keeping the existing cache
fingerprint contract.
</objective>

<task id="43-01-02" name="Implement F5 preset catalog and config field">
<read_first>
- saymo/config.py
- saymo/tts/selector.py
- config.example.yaml
</read_first>
<action>
Add `pause_preset: str = "approved"` to `F5TTSConfig`.
Create `saymo/tts/f5_presets.py` with:
- frozen dataclass `F5PausePreset`
- constants for `approved`, `crisp`, `calm`, `deliberate`
- `list_f5_pause_presets() -> tuple[F5PausePreset, ...]`
- `get_f5_pause_preset(name: str) -> F5PausePreset`
- `apply_f5_pause_preset(config: SaymoConfig, name: str) -> F5PausePreset`

Use these exact preset values:
- approved: sentence=0.38, clause=0.18, silent_breath=0.60, interval=2
- crisp: sentence=0.26, clause=0.12, silent_breath=0.42, interval=2
- calm: sentence=0.44, clause=0.22, silent_breath=0.68, interval=2
- deliberate: sentence=0.55, clause=0.28, silent_breath=0.85, interval=2

Update `_engine_config_payload()` to include `pause_preset`.
Update `config.example.yaml` with `pause_preset: approved` and comments naming
the preset commands.
</action>
<acceptance_criteria>
- `saymo/tts/f5_presets.py` contains `class F5PausePreset`.
- `saymo/config.py` contains `pause_preset: str = "approved"`.
- `saymo/tts/selector.py` includes `"pause_preset": f5.pause_preset`.
- `config.example.yaml` contains `pause_preset: approved`.
- Focused tests from task 43-01-01 pass.
</acceptance_criteria>
</task>

<task id="43-01-04" name="Implement f5-presets list/show/apply CLI">
<read_first>
- saymo/commands/voice_clone.py

- tests/test_voice_clone_cli.py
</read_first>
<action>
Add `@main.group("f5-presets")` in `saymo/commands/voice_clone.py` with:
- `list`: renders a Rich table with columns `preset`, `sentence`, `clause`,
  `silent_breath`, `interval`, and `description`.
- `show <preset>`: prints the same concrete values for one preset.
- `apply <preset>`: options `--profile/-p` and `--config-path`; default write
  path should be the loaded config path when available, otherwise
  `~/.saymo/config.yaml`. The command must read existing YAML, update
  `tts.f5tts.pause_preset`, all four timing fields, and when `--profile` is
  supplied update `meetings.<profile>.voice.f5_pause_preset`.

Expose the loaded config path by storing it in Click context in the CLI
bootstrap if not already available. Do not print config secrets.
</action>
